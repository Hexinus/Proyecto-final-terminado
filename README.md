Foro API

API REST desarrollada con Spring Boot que permite gestionar tópicos de un foro.
Actualmente permite crear, consultar, actualizar y eliminar tópicos usando peticiones HTTP.

La aplicación utiliza una base de datos en memoria H2 Database Engine y el servidor embebido Apache Tomcat.

Requisitos

Para ejecutar el proyecto necesitas tener instalado:

Java 17 o superior

Apache Maven

Un cliente para probar APIs como Postman o Insomnia
